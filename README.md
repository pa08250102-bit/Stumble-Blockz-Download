# Stumble blockz Discord Bot

## Comandos

- `/ping` — verifica se o bot está online.
- `/download` — recebe dois links:
  - `pc` — link do download para PC
  - `mobile` — link do APK

O bot lê o token exclusivamente da variável/Secret `DISCORD_TOKEN`.

## Instalação

```bash
npm install
npm start
```

Não coloque o token diretamente no código.
